# Madhur Wanjari — Portfolio

Responsive portfolio built with HTML, CSS, and JavaScript. Design direction: bold red/blue geometric shapes, editorial typography, asymmetrical hero, and minimal project cards.

## Run in VS Code
1. Extract this ZIP.
2. Open the `madhur-portfolio-redesigned` folder in VS Code.
3. Use the **Live Server** extension.
4. Right-click `index.html` → **Open with Live Server**.

## Gallery
Photos are stored in `assets/gallery/` and referenced with relative paths:
- `moment1.jpeg`
- `moment2.jpeg`
- `moment3.jpeg`
- `moment4.jpeg`

Keep the folder and filenames unchanged unless you also update `index.html`. Profile photo is `assets/profile.jpg`; certificate PDFs are in `assets/certificates/`.

## Publish with GitHub Pages
Upload the folder contents to your GitHub repository. Open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.

## Before publishing
- Replace placeholder LinkedIn URLs with your real profile URL.
- Replace `YOUR_EMAIL@example.com` in `script.js` with your email.
- Update project links to their individual repository URLs if available.
- Add only verified academic marks, achievements, and experience details.

## Files
- `index.html` — page content
- `style.css` — visual design and responsive layout
- `script.js` — mobile menu, theme toggle, contact form
- `assets/` — profile, gallery photos, certificates
